# 实时语音

开发候选版本 `v0.3.0-beta.38` 使用独立配置的 OpenAI Realtime 服务。实际云账号、麦克风、扬声器和 Windows 设备恢复需在对应环境验证；本地受控协议测试不代表这些外部条件已通过。

在设置 → 语音中启用 Realtime，填写自己的密钥、模型和音色。聊天中的实时语音面板先选择业务 Bot，再点击连接。首次连接需要系统麦克风权限。每轮点击开始说话，结束本轮并提交后才发送本轮音频；提交会关闭当前录音轨道。后续轮次再次点击开始。一次连接最长 15 分钟，不自动重连或重新开启麦克风。

输入使用实际 AudioContext 采样率下混并连续重采样为 24 kHz 单声道 PCM16。回复由本地 AudioWorklet 播放。被浏览器阻止时需点击启用音频。打断立即清空本地播放，并以实际处理过的采样数向服务截断上下文；尚未收到截断确认时不会继续下一轮。网络中断保留明确的未知状态。

实时语音只接受最终转录作为普通用户请求。模型的委派提示保留在私有审计记录，不会替换转录、选择会话、增加群成员、授予资料或批准写操作。业务任务进入已有 Runtime 和审批流程；群聊仍支持六成员并行。最终转录与任务链接可在聊天中核对，语音来源单独标识。

“停止语音通话”关闭连接、录音和播放；已经接收的业务任务可继续执行。“停止已委派任务”只停止该轮实际链接的 Runtime 或群批次。切换会话、清空聊天、文档失效、配置变更或授权撤销会关闭旧语音连接。资料版本固定为连接时的明确选择；移出再加入群成员、重新绑定资料都不会恢复旧连接的授权。

密钥只存宿主密钥库。Renderer 不持有 WebSocket 凭据，AI 不能调用麦克风开启、PCM 上传或播放回执。AI 可查询自身来源的连接状态、停止语音或停止其实际链接的业务任务。目录状态不表示已批准外发或已确认设备可用。

本实现固定使用 `realtime-v1` 协议及 `/v1/realtime`。不同协议、错误的音频格式、未确认的配置、取消中的工具调用或不匹配的函数结果会被拒绝。崩溃后仅按已保存 nonce 查询业务接收记录，不重放未知副作用。暂不提供自动 VAD、会议助手或原始通话录音保存。
