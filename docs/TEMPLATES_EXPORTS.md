# 便携模板与选择范围离线导出

当前为 v0.3.0-beta.44 源码候选。模板、界面和 AI 调用使用同一校验业务层；发布安装包及平台验收状态以实施记录为准。

在聊天右上角“聊天选项”选择“模板与选择范围导出”，或从设置的通用页进入。所有候选项初始不勾选，打开时固定当前会话。选择需要的 Bot 配置、群成员、资料固定版本及具体文件；填写名称后预览完整清单，再确认保存新模板或按 expectedVersion 保存新版本。冲突保留选择和预览，不覆盖其他修改。历史版本可以审阅和分别导出。

模板包含选中的名称、角色指令、内置头像配置、群成员结构、资料/Skill 正文和具体文件。图片头像、模型连接、密钥、Memory、聊天历史、MCP、工作区权限、浏览器登录态和运行中任务不进入模板。文件复制到应用拥有的内容寻址存储；源目录移动或移除后，保存的模板仍可导出。

导入时选择真实 JSON 文件，校验格式版本、大小、文件摘要和路径，展示完整清单。确认后创建独立 Bot 与群副本，资料绑定到明确选择的会话；Skill 初始停用，不授予脚本权限，不自动运行。相同导入 nonce 和摘要只返回原回执；内容改变报告冲突。取消不发布半成品，未发布的预览不会在重启后自动恢复。

离线导出只保存选中消息、资料固定版本、具体文件和媒体。消息选择同时固定世代与正文摘要；无关会话、Memory、凭据和工具内部参数不会混入。可以保存 JSON 或独立 HTML；HTML 不执行脚本、不依赖网络，包含选中文件与媒体的内嵌字节。导出前后重新检查授权；已撤销的资源不会完成发布。通过系统对话框选择保存位置，不覆盖已存在文件。取消当前操作只取消该操作，不停止其他群成员任务。

AI 通过 product_catalog → product_describe → product_execute 使用 templates.list/read/versions/prepareCapture/commitCapture/prepareImport/pickImport/commitImport/export 和 exports.save。AI 只能读取实际 Runtime 会话与成员授权，模板版本在 Runtime 开始时固定；重试保留原准入，后建模板不会自动进入旧任务。AI 不能消费用户界面的预览令牌。创建/导入审批展示完整清单，元信息不能授予新权限。TASK 不允许模板导入创建新联系人。完整指令、模板名和资料正文使用临时且可撤销的模型文本载荷，持久工具回执只保存标识、数量和摘要。

原子数据库修改和成功回执一起提交；原操作已完成时重试不会重复创建。保存对话框属于本机交互，模型不能指定宿主任意路径；中断而未确认的保存不会自动重新打开或覆盖文件，需要用户核对后在新任务中处理。未提供公共分享服务或联网同步。

无新增依赖。真实第三方账号、Windows 安装包、签名发行和远程部署不能从本地源码检查推断为已验证。
