# 聊天整理、通知与 Bot 图片头像

beta.41 开发候选提供界面和 AI 共用的本地整理能力。公开安装版本与候选验证分开记录；跨平台、签名发行及真实系统通知仍需各自验收。

## 分区与默认助理

在聊天列表选择 **整理聊天**，或打开 **设置 → 通用 → 聊天整理与通知**。可以创建、改名、删除和排序分区，将 MAIN 或 TASK 会话移入分区，并在分区内排序。归属按实际 sessionId 保存；删除分区会把聊天放回未分组，保留聊天本身。分区不共享历史、资料或授权。

默认助理仅在启动时没有有效的上次聊天可恢复时打开，不替换已选 TASK、群聊或 Bot。分区和偏好采用版本校验；其他位置修改后，当前名称、归属和偏好草稿会保留，选择 **读取最新版本，保留编辑** 后核对再保存。

## 通知

审批、任务完成、任务失败和 Routine 通知分别设置；通知声音独立设置。默认保留既有审批和 Routine 通知，新增完成／失败通知默认关闭。实际送达还受系统权限、前台状态和平台支持限制；界面勾选不证明系统已显示通知。

## Bot 图片头像

在 **联系人 → 选择 Bot → 资料 → 更换图片头像**，从当前私聊 MAIN 资料中选择已导入的 PNG/JPEG（最大 2 MiB）。宿主读取真实授权字节，居中裁剪并保存 256×256 PNG。发布后图片作为该 Bot 的公开资料头像显示在它的聊天和群成员位置；选择前会明确提示这一范围。

头像保存为应用拥有的独立副本。删除原媒体或移动原文件夹不会移除已发布头像。复制 Bot 创建独立的图片资源身份；**恢复默认头像** 只清除所选 Bot 的图片，并继续使用原有默认头像。并发资料版本变化或来源撤销会拒绝提交，取消不会发布半成品。

## AI 调用

模型继续通过 `product_catalog → product_describe → product_execute` 访问 `organization.snapshot/createSection/renameSection/deleteSection/reorderSections/moveSession/savePreferences` 与 `bots.setImageAvatar/clearImageAvatar/readImageAvatar`。实际 Runtime 会话、执行 Bot 和 TASK 原授权决定可用范围；移动操作只处理当前会话。修改走现有审批和版本规则。

设置头像只能使用本任务实际获准的媒体，不能从其他私聊读取原图。读取已发布头像按模型的真实图像传输能力返回像素；不支持图像的模型只获得明确限制和元信息。持久工具记录不保存图片字节。原生取消和读图 IPC 不构成模型的额外权限。

## 当前验证

本地首轮 54 项相关业务回归，以及后续头像原子回执／真实模型像素等三文件 56 项回归、完整类型与构建通过。两项隐藏 Electron 场景同轮通过，覆盖真实 SQLite／IPC、分区排序与并发草稿、默认助理恢复，以及原生图片裁剪、真实像素、源删除、重启、复制和恢复默认。实际未签名 macOS 包首轮六项通过；头像回执修复后新包三项定向复验通过。Windows、签名发行和物理通知仍待验证。证据记录见[实施计划](IMPLEMENTATION_PLAN.md)。不新增依赖或许可。
