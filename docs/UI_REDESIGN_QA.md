## 改造范围

- 左侧导航轨道、混合最近聊天列表、联系人、文件夹工作区与项目树。
- 聊天标题、消息/头像、日期分隔、消息上方的协作详情、真实交付物卡片和多行输入区。
- 标题右侧统一为聊天选项菜单；模型切换、文件、执行记录、详情与恢复操作仍可访问。
- 群聊响应方式放在输入区工具行；保留 `@`、指定 Bot、全员和自动编排业务逻辑。
- 七个设置页、Bot/群聊资料抽屉、权限确认、新建入口和个人资料。
- 七款卡通人物 Bot 头像、默认山景用户头像；用户昵称/头像本地保存，256px 居中裁切，不上传至模型或账号服务。
- 两套共享主题 token、图标库、组件间距、焦点和响应式规则；已有数据、Provider、Memory、工具授权和删除边界保留。

## 真实模型 / 工具业务回归

UI-only `ui-design-reference.spec.ts` 中的消息、时间、联系人和 Runtime 状态为明确标注的**视觉测试 fixture**，不作为 Agent 执行、真实协作或模型正确性的依据，也不作为对外宣传截图。

另行真实业务验收共**6个场景通过**，删除了 Fake Provider 环境变量，使用真实安装配置和已登录 CLI，只复制 API 配置，不复制用户聊天、记忆或任务：

1. API：协调者自动安排研究/编辑、真实读写文件、下游读取上游产物、自动接力与汇总。
2. Claude Code：真实扫描已登录 CLI、切换实际调用、文件工具与协作链路。
3. Codex CLI：真实扫描已登录 CLI、切换实际调用、文件工具与协作链路。
4. 同一 Bot 加入两个文件夹项目：读取、写入、核对严格使用当前群工作区。
5. 指定 Bot、全员、无点名自动路由与协调者问候：真实请求，避免重复调度。
6. 真实缺失文件异常：保留失败证据、恢复实际 LICENSE 文件后点击一次正常重试，自动恢复下游，不重新发请求、不补上下文、不人工调度；核对单次写入、hash与接力回执。
