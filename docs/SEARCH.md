# 全资源搜索

开发候选：v0.3.0-beta.40。本地搜索业务、真实 SQLite 和隐藏 Electron 界面已验证；当前安装包、跨平台 CI 和签名发行仍是独立门禁。公开可下载版本请查看 [Beta Releases](https://github.com/CMSKL/Aevoren-Bot/releases)。

## 使用界面

点击聊天／联系人列表搜索框左侧的搜索按钮，打开「全资源搜索」。默认查找当前会话，可以明确选择全部本地资源或当前项目，并按消息、资料、Skill、媒体与转录、任务线程、自动任务、应用草稿筛选。输入关键词后点击搜索；结果较多时加载下一页。

关键词按 Unicode NFKC 规范化并忽略大小写，作为普通文字匹配，不执行查询表达式。匹配过多时需要缩小范围。这里只检索已经保存且有权限读取的本地内容，不抓取互联网、宿主目录或连接账号中的全部远程内容。

点击消息会打开原会话并定位原条目；TASK 明确选择的历史可定位其原会话。清空、删除或授权变化后，不会用文字相似的新条目替代原结果。资料和 Skill 按搜索时固定的版本展示；来源后续编辑不会把旧结果改成新正文。撤销或停用后，重新打开会被拒绝。

媒体使用现有真实像素／文件预览。PDF、DOCX 的已保存解析文字及已有 STT、实时语音转录可以检索；视频只检索已保存元信息，不提供视频理解或 OCR。应用草稿只检索本地保存且仍有授权的版本，不会发送邮件或写入第三方应用。

## AI 入口

AI 通过 `product_catalog → product_describe → product_execute` 调用 `search.query` 和 `search.open`。宿主根据实际 Runtime 固定当前会话和执行 Bot；模型不能选择全局、其他项目或兄弟会话。TASK 检索继续使用原 Runtime 明确选择的资料版本、历史和成员授权。

`search.open` 重新核验原会话、世代、版本、摘要和授权，只返回经过验证的来源引用。搜索标题和正文片段通过可撤销的私有模型文字附件传输；持久工具回执只保存数量、游标、摘要和来源引用。实际模型发送前再次核验，撤权或删除后的缓存正文不会继续发送。

搜索不索引凭据、OAuth Token、原始语音音频、私有函数参数或未选择的会话内容。搜索结果和工具目录本身不会授予新的权限。

## 验证范围

- 11 项搜索真实 SQLite 测试覆盖七类资源、已保存转录、规范化、固定版本、旧 Runtime、权限隔离、分页游标、绑定撤销和历史世代。
- 两项产品传输测试检查私有标题／片段不进入持久回执，以及 MAIN 撤权和 TASK 原始版本的发送前检查。
- 两项隐藏 Electron 场景验证界面分页、历史版本预览、撤权、原消息定位、TASK 所选历史和清空后相同文字不替代原来源，拥有的应用进程均正常退出。
- 受控数据测试不证明真实云账号、物理设备或第三方写操作已验证。安装包和发行证据见 [实施计划](IMPLEMENTATION_PLAN.md)。
